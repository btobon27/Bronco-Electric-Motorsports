## Design

Board was designed for LiFePO4 12V 100Ah battery
Current draw calculated and measured between 20A to 25A

Gate driver used to drive large power MOSFETs for pumps larger inductive fans and pump loads

Flyback diode protection for respective power FETs and inductive loads
