# Formula SAE Electric PCB Projects

PCB designs developed for the Cal Poly Pomona Formula SAE Electric vehicle. These projects focus on low-voltage vehicle control, safety systems, power control, and electrical system integration.

All PCB designs were developed using KiCad.

## Projects

### Vehicle Control Unit (VCU)
Redesign of the vehicle's central low-voltage controller. The VCU interfaces with vehicle sensors, driver inputs, CAN communication, safety systems, and other vehicle electronics while maintaining compatibility with existing daughterboards.

### Low Voltage Control
Redesign of the vehicle's low-voltage control PCB. The board provides the electrical interface for controlling and distributing signals to various LV loads and vehicle systems.

### Fault Latching Circuit
Hardware safety circuit used to latch faults from critical vehicle systems and maintain the fault condition until the appropriate reset condition occurs. The design interfaces with the Formula SAE Electric shutdown circuit and is being refined from the previous vehicle design.

## Design Process

Each project follows a structured engineering process:

Requirements → Previous Design Evaluation → Schematic Design → PCB Layout → Design Review → Manufacturing → Testing → Vehicle Integration
